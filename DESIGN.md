# Дизайн-система «ФСП Таланты»

Интерфейс собран в цветах и мотивах брендбука ФСП (`брендбук/`): фиолетовый `#402FFF`, красный из логотипа, графит, шрифт JetBrains Mono для меток и цифр, тонкие «дорожки» с точками на концах. Две темы — светлая и тёмная (по образу тёмного стенда ФСП); по умолчанию тема следует настройке системы, переключатель в шапке закрепляет выбор.

Правила ниже защищены тестом `tests/unit/design-tokens.test.ts`: если их нарушить, упадёт `npm test`, а с ним и CI.

## 1. Цвет — только через токены

Все цвета живут в `app/globals.css` в блоке `@theme`. Каждый токен задан одной парой `light-dark(светлая, тёмная)`, поэтому новый токен не может «забыть» про тёмную тему. Стандартная палитра Tailwind выключена: `bg-white`, `text-gray-500`, `bg-violet` не сгенерируют стилей.

| Токен                                      | Для чего                                                                       | Пример                                |
| ------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------- |
| `canvas`                                   | фон страницы                                                                   | `bg-canvas`                           |
| `surface`                                  | карточки, поля ввода, меню                                                     | `bg-surface`                          |
| `subtle`                                   | второй слой: подложки, hover строк                                             | `hover:bg-subtle`                     |
| `fg`                                       | основной текст                                                                 | `text-fg`                             |
| `muted`                                    | второстепенный текст, подписи                                                  | `text-muted`                          |
| `line`                                     | нейтральные рамки, разделители, поля                                           | `border-line`                         |
| `primary` / `primary-hover` / `on-primary` | заливка главного действия и выбранного чипа, текст на ней                      | `bg-primary text-on-primary`          |
| `accent`                                   | фирменный «чернильный» цвет: ссылки, заголовки, рамки бланков, иконки          | `text-accent`, `border-accent/45`     |
| `accent-soft`                              | мягкая фиолетовая подложка: активный пункт меню, выделение                     | `bg-accent-soft`                      |
| `danger` / `ok` / `warn`                   | статусы                                                                        | `text-danger`, `bg-ok/5 border-ok/30` |
| `red`                                      | красный логотипа, только маленькая заливка (точка уведомления, призовое место) | `bg-red`                              |
| `code` / `code-fg`                         | блоки кода и редактор — тёмные в обеих темах                                   | `bg-code text-code-fg`                |

Прозрачность — через модификатор: `border-accent/45`, `bg-danger/5`. Литералы (`#fff`, `rgb()`, `bg-[#…]`, `style={{ color: "#…" }}`) в `app/` и `components/` запрещены. Если файлу правда нужен свой набор цветов (палитра подсветки синтаксиса), он ставит комментарий `design-tokens: allow-raw-colors` с причиной.

Нужен новый цвет — добавьте токен в `@theme` (с парой `light-dark`, контраст текста ≥ 4.5:1 в обеих темах) и строку в эту таблицу.

Вариант `dark:` используется только внутри `components/ui/` и только для того, что токеном не выразить (подмена файла логотипа). В страницах и фичах его нет.

## 2. Готовые компоненты — `components/ui/`

Прежде чем писать разметку, возьмите готовое:

| Нужно                                                              | Берите                                                                                                                                |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Кнопка / кнопка-ссылка                                             | `Button`, `ButtonLink`, `buttonClass(variant, size)` — `primary`, `secondary`, `ghost`, `danger`                                      |
| Заголовок страницы                                                 | `PageTitle` — `title`, `meta` (дата, компания, шаг), `back` (ссылка к списку на детальной странице)                                   |
| Блок-«бланк» с меткой                                              | `Blank` (`label`, `aside`)                                                                                                            |
| Список однотипных строк                                            | `<ul className="list-frame">` — одна рамка, строки через разделители, hover `bg-subtle`. Не делайте каждую строку отдельной карточкой |
| Пустой список                                                      | `EmptyState` — заголовок, почему пусто и что сделать, опционально кнопка                                                              |
| Фильтр / выбор грейда / вкладка                                    | `chipState(selected)` + свои отступы, плюс `aria-pressed` / `aria-selected` / `aria-current`                                          |
| Статус, метка                                                      | `Badge` (`violet`, `red`, `gray`, `ok`, `warn`, `solid`)                                                                              |
| Поле формы                                                         | `Field` + класс `.input`; сообщение — `Notice`                                                                                        |
| Логотип                                                            | `Logo` (сам меняет файл под тему)                                                                                                     |
| Декоративная «дорожка»                                             | `Track`                                                                                                                               |
| Генеративный фирменный паттерн (обложки статей, сертификаты, фоны) | `Pattern` (`seed`, `animated`, `density`) — один seed всегда даёт одну картинку                                                       |
| Число, которое «досчитывает» при появлении                         | `CountUp`                                                                                                                             |
| Модальное окно (уведомления, чат)                                  | `Modal` — на телефоне на весь экран, от `sm` по центру; Esc, клик по фону, фокус остаётся внутри                                      |

## 3. Типографика

- Golos Text — весь текст и заголовки; JetBrains Mono — только метки (`.label-mono`), цифры, даты, суммы, код. Не используйте моноширинный шрифт «для техничности».
- Заголовок страницы — один `h1` через `PageTitle`. Надписей-«кикеров» над заголовком нет: где вы находитесь, показывает активный пункт меню.
- Цифры в `font-mono` и `<time>` выравниваются (tabular-nums) автоматически.
- Длинные заголовки — `text-balance`, абзацы — `text-pretty`, ширина текста — до `max-w-prose`.

## 4. Навигация и раскладка

- Пункты меню роли задаются в `components/layout/header.tsx` (`navByRole`). Активный пункт подсвечивается сам; от `xl` и ниже меню сворачивается в кнопку с названием текущего раздела.
- Контент — в `max-w-6xl`, поля `px-4 sm:px-6`. Проверяйте каждую новую страницу на ширине 390 px: ничего не обрезается и не прокручивается вбок.
- Тени — только у всплывающих элементов (`shadow-pop`). Карточкам хватает рамки.

## 5. Состояния и доступность

У каждого интерактивного элемента есть hover, фокус (`:focus-visible` стилизован глобально), disabled и, где есть загрузка, текст «…ется». Ошибки называют проблему и что делать. Иконки — inline SVG с `aria-hidden`, у кнопки-иконки есть `aria-label`. Анимации интерфейса короткие (150–250 мс) и отключаются при `prefers-reduced-motion`.

Декоративное движение — только готовыми классами из `app/globals.css`: `.rise` (появление при загрузке, задержка через `style={{ "--d": "120ms" }}`), `.reveal` и `.grow-bar` (при прокрутке, где браузер поддерживает scroll-driven animations), `.pattern-draw`/`.pattern-pop` (дорожка рисуется, «молекула» появляется), `.marquee`, `.float`, `.ping`, `.motion-only` (SMIL-анимации внутри SVG). Все они выключены при `prefers-reduced-motion`, а контент виден и без них.

## Чек-лист для новой фичи

1. Цвета — только токены из таблицы; запустите `npm test`.
2. Компоненты — из `components/ui/`; не хватает — добавьте туда, а не копируйте классы по страницам.
3. Посмотрите страницу в светлой и тёмной теме (переключатель в шапке) и на ширине 390 px.
4. Пустое состояние, ошибка и загрузка продуманы.
